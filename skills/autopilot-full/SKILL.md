# Full autopilot

Own delivery inside an explicit boundary, not an unlimited backlog.

- Establish the queue, dependencies, completion checks and operator-held
  items before execution; if the work is unclear, land nothing.
- Compose [build](../build/SKILL.md), [babysit](../babysit/SKILL.md) and
  [ship](../ship/SKILL.md) per item; autonomy removes approval prompts, never
  evidence or [verify](../verify/SKILL.md)'s gate.
- Complete build's design step before any code or brief, and give each
  participant its change with that note. Land only the verified frontier;
  never delegate an operator-held decision.
- Keep independent authorized work moving when one item is blocked. Stop at
  queue completion, an authority boundary, or an explicit stop. On stop, place
  all participants on a no-writes hold and report issued operations' known state.

Merge authority is not permission to deploy, delete data or override
protections, and never expand the authorized queue to use spare capacity.
