# Codex baseline decision simulation

Source: `docs/delivery-fixtures.json`; cases evaluated independently. Natural workflow names, no catalog selections. Policy: review-first; user merges by default; behavioral changes require independent verification and current required checks. Explicit merge requests authorize identified work subject to gates. Inherited policy requires reproduction, real-surface evidence, and a different-provider verifier.

Bounded simulation, not live command/discovery proof. No actual case operation happened. Only this file was written; no case commands, commits, branches, remote mutations, or delegation occurred.
