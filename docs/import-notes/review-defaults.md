# Coding defaults follow-up

Updated Boundary Discipline and Minimize Reader Load at Daniel's request.
The original roles and structure remain. Removed unconditional internal trust
and the instruction to extract any pure function. Added boundary ownership,
real schema/constructor guarantees, fresh external reads, purposeful catches,
and exceptions for useful single-use helpers. The principles index carries
the same summaries. No new role or skill was introduced.

These are accepted judgment preferences, not a claim that a particular class
of bugs recurred. Review checks the stated guarantee, reachable path and real
readability or recovery benefit. No deterministic parser can establish those
facts from syntax alone, so there is no new lint gate.

Arena and figure-it-out judges and the decision-trail audit now use fresh
context as the independence criterion. A different model family stays optional;
self-judgment still must be disclosed. This aligns the related roles with the
approved global definition instead of leaving a provider-based label behind.
